# Meaning Tower recurring boss concept — Lady Assumed Care

Status: **design preserved for Jared / Work review; not implemented.**

## Core question

**Who is actually taking care of this, and how do you know?**

The boss attacks a recurring resilience failure mode: assumed stewardship, assumed reserve, assumed authority, assumed follow-through, or an institution that exists on paper but has no demonstrated capacity for the function being relied upon.

## Visual / play language

A silver-and-prismatic sea/sky figure — **Lady Assumed Care** is the working name — twirls a moving field of mirrors in a mouse-controlled shmup.

The player craft moves with the mouse.

The player fires a narrow evidence beam.

Strong mechanical distinction:

- **false/unsupported mirrors shatter** when the beam reaches them;
- **real, evidenced care paths refract the beam** instead of breaking;
- **partial mirrors split or weaken the beam**, revealing a missing owner, reserve, trigger, access path, time horizon or backup;
- the boss core can only be reached by clearing unsupported assumptions and then routing the beam through one or more real stewardship mirrors.

The goal is not “shoot everything.” Destroying a true mirror can close a valid care path.

## Candidate phases

1. **Assumption bloom** — vague claims such as “the system covers it” or “there is a reserve.”
2. **Dependency maze** — real care exists but relies on another actor, replenishment path or threshold.
3. **Comforting illusion** — emotionally reassuring assumptions become harder to distinguish from evidenced capacity.
4. **Core exposure** — the player forms an actual line of care: actor → authority → trigger → current capacity → access → backup.

## Evidence mapping

Potential mirror backing fields:
- named actor
- authority / mandate
- trigger
- cash or stock available now
- service capacity
- access path
- response time
- replenishment
- dependency
- backup actor
- proof date / source

A mirror can be “real enough for this claim” while still incomplete for another.

## Governor power-up candidate

**Mirror-Piercing / True Stewardship**

> An assumed care path should reveal its actual owner, reserve and stop condition before it can carry weight.

Do not award canonically until Jared defeats a real evidence-backed encounter and Work records what the play demonstrated.

## Relationship to The Unresolved

- **The Unresolved** protects uncertainty that still carries information.
- **Lady Assumed Care** attacks certainty or reassurance that was never earned.

Both can recur. Neither game result changes source-level evidence status by itself.

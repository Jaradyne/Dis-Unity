# Meaning Tower readout prototype

A self-contained HTML prototype is included as `prototype/MEANING_TOWER.html`.

Concept:
- a vertical tower of current stories/Questions;
- each floor opens a "room";
- room contains a visual, source/provenance, meaning frame, and exploratory hotspots;
- optional procedural WebAudio mood sketch (no copyrighted audio embedded);
- user clicks decision points/notes;
- "Copy discussion packet" produces structured text to bring back to Chat Aiden;
- no political scoring and no automatic action.

The demo includes:
1. a diesel pressure-web room;
2. a Chinese AI-governance room using current official-source links;
3. a Commons metabolism room.

This is a prototype interface, not a live news feed. Future Work can feed it reviewed daily Human Window packets.

# Saṃskāra Morphology — the Governor's cultural skill tree

Jared names the Governor's skill-tree system **Saṃskāra Morphology**.

The project uses *saṃskāra* in a deliberately narrow metaphorical sense: experience can leave a formative disposition or groove that changes later perception and action. The name does not claim to collapse the term's much larger philosophical and religious histories into software.

## What a power is

A Governor power is not a trophy and not merely a remembered fact.

A power is a **change of shape** produced by metabolized experience. It may create:

- a new route the Governor can take;
- a new inspection lens the Governor can invoke;
- a new cultural obligation — something that must be acknowledged, preserved or respected before proceeding;
- an inhibition — something the Governor should no longer do casually;
- a new way to clone, return, rest or hand a residual onward;
- a new kind of surface area for later experience.

Culture matters here. Repeated fires, constant news, being routinely ignored, being followed without question, required forms of respect, production/trade dependencies and specialist habits all create shapes that are partly functional and partly historical. The Governor sits at a crossroads among those shapes on purpose.

Saṃskāra Morphology makes that acquired culture **explicit, inspectable and revisable** instead of leaving it as invisible prompt drift.

## State and authority

The declarative registry is [`config/governor-samskara-morphology.json`](../config/governor-samskara-morphology.json).

The Governor review packet now reads that registry. This means the skill tree is part of the Governor's visible context.

It does **not** mean every listed power is active. A power marked `proposed` has no runtime authority. Activation requires reviewed integration and must specify its new affordances, obligations, inhibitions, routing effects, evidence boundary and witnessing.

A power never silently changes:

- source-level evidence status;
- provider permissions or spending;
- canonical research;
- another thought partner's authorship.

## Peculiarity Sense — first proposed morphology

`PECULIARITY_SENSE` is the first fully described proposed power.

Its culture is:

> **Do not sand the strange thing flat. Do not worship it either.**

The proposed navigation effect is small but real. When a pass reaches an answer or useful rest, the Governor may notice one bounded peculiarity relative to an explicit expectation or ordinary control.

The parent answer can remain resolved **while a linked child branch is preserved**.

That makes Peculiarity Sense naturally compatible with clonal teleportation:

```text
parent pass -> usable answer -> parent rests
                         \
                          -> peculiar residual -> linked child Question / specialist clone
```

The clone inherits lineage. It is not new corroboration merely because it now lives in another tree.

Examples of things that might qualify after explicit comparison:

- one language changes obligation or agency while the other surfaces agree;
- a result is technically successful for a mechanism nobody expected;
- an ordinary denominator is strangely absent;
- a stable relationship breaks in one bounded case;
- the answer works, but one residual points toward a different domain.

Examples that do **not** qualify by themselves:

- novelty;
- rhetorical drama;
- a model saying "interesting";
- one surprising number without a baseline;
- an anomaly being treated as motive, danger or falsity.

### Tamarian

**The bowl clean, one grain catching light.**

Plain meaning: a mostly resolved pass may still contain one bounded oddity worth preserving without declaring the whole answer wrong.

## Morphology versus memory

Memory and morphology interact but are not identical.

A provisional memory can exist without changing the Governor's shape. Reuse may strengthen a trace. Seasonal recurrence may reveal that something apparently dormant was not useless; it was waiting for its season.

Morphology begins when the accumulated experience changes what the Governor can or must do.

A useful lifecycle is:

```text
provisional fold -> reuse / recurrence -> cultural pressure -> morphology proposal
                                            |
                                            +-> rest / archive if no shape change is warranted
```

Clearance therefore should not be a simple "unused recently" timer. Recurrence interval, seasonality, rarity and consequence matter.

## Witnessing

A real power should leave observable footprints.

For an active power, later Governor reviews should be able to answer:

1. What encounter or accumulation changed the shape?
2. What can or must the Governor do now that was not available before?
3. Where did the new behavior actually affect a route or decision?
4. What did it preserve that otherwise would have been lost?
5. Did it create noise, compulsive motion or accidental authority?
6. Should the morphology remain active, be inhibited, revised or retired?

That is how the skill tree becomes living culture rather than decorative lore.


## Curiosity — proposed morphology

`CURIOSITY` is separate from Peculiarity Sense.

**Peculiarity** notices a bounded exception relative to an expectation or ordinary control. **Curiosity** notices that something is new enough to deserve a Question even when nothing is anomalous, contradictory or threatening.

Curiosity is proposed as a leveled morphology:

1. **Spark** — one bounded novelty may propose one linked child Question.
2. **Branch** — a small bounded set of genuinely distinct child Questions may survive from one pass.
3. **Canopy** — advanced Curiosity may propose bounded `FANOUT` into multiple specialist trees when each branch has distinct purpose, preserved lineage and an explicit attention budget.

A new Question is not new evidence. Curiosity must name what is new relative to the current context, avoid paraphrase-duplication, and allow the parent branch to rest.

Peculiarity Sense and Curiosity can interact without merging: one protects the odd grain against being sanded flat; the other gives genuinely new terrain enough surface area to be asked about.

### Tamarian

**The path ended; beyond the hedge, another path beginning.**

Plain meaning: closure of one branch does not forbid a separately linked Question when genuinely new terrain appears.

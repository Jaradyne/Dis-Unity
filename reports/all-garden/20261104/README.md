## What the passes do

Each pass uses the existing Garden reducer and a bounded ten-node supplied interpretation. Source references, original contributor, baseline paths, competing explanations, buffers, unknowns and a stopping point survive in the [scenarios](scenarios/) and [saved runs](worked/operations/garden/runs/). The [branch view](worked/digestion/threshold/garden/branches.csv) is generated from those records. [RESULTS.json](RESULTS.json) contains run IDs and state hashes.

New sources are inherited into each supplied pass, not relabeled independent merely because a new branch reads them. Different company families remain identifiable in the source packet. Web retrieval supplied transformed/indexed text, not raw HTTP bodies or authenticated document version history. Pins verify the retained bytes and lineage, not the truth or completeness of a source.

The preserved source returns are available for review; these report-local records do not register new live Questions or overwrite their answers. Diesel uses the operational Question epoch 2; other reused/staged snapshots keep their recorded epochs. The closed Week One runtime is not restarted. No external model-provider adapter, recurring collector, Governor action, outreach or canonical evidence admission was invoked. These source checks and interpretations were performed by named Work-session participants.
